# Free Accountant Website

1. Open `index.html` in Chrome to test the website.
2. Replace the sample mobile number `9999999999`, email, UPI ID and city in `index.html`.
3. Put your own UPI QR image in this folder and name it `qr.png`.
4. Upload all files to GitHub and enable GitHub Pages for free.

Files:
- index.html
- style.css
- script.js
- qr.png (add your own QR)
